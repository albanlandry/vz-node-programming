# Graph Editor - 사용 가이드

## 개요

웹 기반 그래프 UI 시스템이 성공적으로 구현되었습니다. 노드, 포트, 연결을 시각적으로 생성하고 관리할 수 있습니다.

## 주요 기능

### ✅ 구현 완료

1. **노드**
   - 드래그 앤 드롭으로 이동
   - 속성 설정 (ID, 이름, 타입, 위치)
   - 입력/출력 포트 포함

2. **포트**
   - 타입별 색상 코딩
   - 입력/출력 구분
   - 필수 포트 표시

3. **연결**
   - 포트 간 연결 생성
   - 타입 검증으로 잘못된 연결 방지
   - Bezier 곡선으로 시각화

4. **Pan & Zoom**
   - 마우스 휠로 줌
   - 중간 버튼 또는 Ctrl+클릭으로 팬
   - 뷰포트 리셋

5. **상태 관리 (Zustand)**
   - 중앙 집중식 상태 관리
   - 반응형 업데이트

6. **영구 저장**
   - JSON 파일로 저장/로드
   - 그래프 상태 보존

## 빠른 시작

### 1. 그래프 에디터 접근

```
http://localhost:3000/graph-editor
```

또는 네비게이션 메뉴에서 "Graph Editor" 클릭

### 2. 노드 생성

1. 툴바에서 "Add Node" 버튼 클릭
2. 노드 이름과 타입 입력
3. "Add" 클릭
4. 노드가 캔버스에 나타남

### 3. 노드 이동

- 노드의 파란색 헤더를 클릭하고 드래그
- 위치가 자동으로 저장됨

### 4. 연결 생성

1. 출력 포트(오른쪽, 색상 점)를 클릭하고 드래그
2. 입력 포트(왼쪽, 색상 점)로 드래그
3. 마우스 버튼을 놓으면 연결 생성
4. 타입이 호환되지 않으면 연결이 거부됨

### 5. 삭제

- **노드**: 노드를 선택하고 Delete 키 누르기 또는 ✕ 버튼 클릭
- **연결**: 연결선을 더블클릭

### 6. Pan & Zoom

- **줌 인**: 마우스 휠 위로
- **줌 아웃**: 마우스 휠 아래로
- **팬**: 중간 마우스 버튼 또는 Ctrl+왼쪽 클릭 드래그
- **리셋**: "Reset View" 버튼 클릭

### 7. 저장/로드

- **저장**: "Save" 버튼 클릭 → `graph.json` 파일 다운로드
- **로드**: "Load" 버튼 클릭 → JSON 파일 선택 → 그래프 복원

## 타입 시스템

### 포트 타입 색상

- 🟢 **Green**: String
- 🔵 **Blue**: Number
- 🟣 **Purple**: Boolean
- 🟠 **Orange**: Object
- 🟣 **Pink**: Array
- ⚫ **Gray**: Other/Any

### 연결 규칙

- **같은 타입**: ✅ 항상 연결 가능
- **Any 타입**: ✅ 모든 타입과 연결 가능
- **Number 타입**: ✅ 서로 호환
- **호환되지 않는 타입**: ❌ 연결 차단

## 키보드 단축키

- **Delete / Backspace**: 선택된 노드 삭제
- **Escape**: 연결 생성 취소
- **Ctrl + Left Click**: 팬 모드

## 기술 스택

- **상태 관리**: Zustand
- **드래그 앤 드롭**: react-draggable
- **렌더링**: React + SVG
- **스타일링**: Tailwind CSS
- **타입 안전성**: TypeScript

## 문제 해결

### 연결이 보이지 않음

- 포트가 올바르게 렌더링되었는지 확인
- 타입이 호환되는지 확인
- 브라우저 콘솔에서 오류 확인

### 노드를 드래그할 수 없음

- 노드의 파란색 헤더를 드래그해야 함
- 다른 요소가 노드를 가리고 있지 않은지 확인

### 줌이 작동하지 않음

- 캔버스 영역에서 마우스 휠을 사용해야 함
- 브라우저의 기본 줌 동작과 충돌할 수 있음
