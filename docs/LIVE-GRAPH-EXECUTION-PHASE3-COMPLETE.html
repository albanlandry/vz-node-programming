성능 개선

Incremental Execution

  • 변경되지 않은 노드는 캐시에서 재사용
  • 변경된 노드와 영향받는 노드만 실행
  • 캐시 히트율 추적
  • 실행 시간 단축 (변경되지 않은 노드 제외)

Caching

  • 해시 기반 캐시 키
  • TTL 기반 만료
  • LRU eviction
  • 캐시 통계 제공

성능 지표

예상 성능 개선

  • 증분 실행: 변경되지 않은 노드가 50% 이상일 경우 실행 시간 50%+ 단축

  • 변경 감지: 100개 노드 기준 < 10ms
