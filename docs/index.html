VZ Programming Documentation

VZ Programming is a node-based programming system that supports multiple programming paradigms using TypeScript/Node.js.

Key Documentation

Node Library

Detailed explanation of how nodes work, available methods and properties, and how to create custom nodes.

Node Registry & Discovery System

Complete guide to the node registration and discovery system. Learn how to register, search, and dynamically create nodes.

Custom Nodes Implementation

Learn how to create custom nodes via web UI. Use the template-based system to create nodes without writing TypeScript code.

Graph Editor

Guide to using the visual graph editor built with React Flow.

Error Handling

Guide to the error handling system. Learn about retry, circuit breaker, fallback, and other features.

Logging

Guide to using the logging system. Learn about different log formats and configuration options.

Features

  • Async Execution: Full support for Promise-based asynchronous operations
  • Parallel Execution: Automatic parallel execution of independent nodes
  • Node Registry: Centralized node management and discovery system
  • Graph Serialization: Export/import workflows as JSON/YAML
  • Error Handling: Retry, circuit breaker, fallback, and DLQ support
  • Logging: Configurable logging system
  • Custom Nodes: Create custom nodes via web UI
  • Graph Editor: Visual editor built with React Flow

To get started with VZ Programming, read the Node Library documentation first.
